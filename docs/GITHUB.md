# Conteúdo do repositório

O código, os testes, as decisões técnicas e os CSVs de catálogo são versionados.
Credenciais, ambiente virtual, downloads locais, cadastros/pedidos, PDFs e
transcrições com trechos do manual interno permanecem somente no workspace.
Nenhum desses arquivos originais é removido.

Para executar uma cópia obtida do GitHub, o responsável deve disponibilizar os
seis CSVs originais e o PDF de políticas em `data/` por um canal autorizado.
Configure as credenciais somente no `.env` local, conforme `.env.example`.
Os links para relatórios e transcrições nos READMEs referem-se a artefatos locais.

As quatro conversas de catálogo permitidas para publicação estão em
[EXEMPLOS_CATALOGO.md](EXEMPLOS_CATALOGO.md). Elas foram extraídas de uma
execução real aprovada e não incluem dados de clientes nem trechos do manual.

O repositório remoto deve ser dedicado a este desafio. O envio só ocorre depois
de verificar os arquivos selecionados; projetos existentes de outros trabalhos
não são reutilizados.
